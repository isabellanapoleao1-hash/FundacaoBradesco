# Fundação Bradesco

Sistema web desenvolvido como parte do Projeto Integrador Extensionista II, do curso de Análise e Desenvolvimento de Sistemas (ADS).

O projeto tem como objetivo desenvolver uma aplicação para apoiar atividades da Fundação Bradesco.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Vite+
- Node.js
- Express
- Git e GitHub

## Requisitos

- Git
- Vite+ (comando vp)

## Como executar o projeto

1. Clone o repositório.
2. Entre na pasta do projeto.
3. Instale as dependências:

   vp install

4. Crie o arquivo .env utilizando o .env.example como modelo.
5. Abra um terminal e inicie a API:

   vp run api

6. Abra outro terminal e inicie o frontend:

   vp dev

7. Acesse no navegador:

   http://localhost:5173
